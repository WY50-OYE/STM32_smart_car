# STM32 智能小车 2.0

基于 STM32 微控制器开发的智能小车项目

## 🌟 功能特点
- HCSR04超声波避障
- HC06蓝牙遥控
- TCRT5000红外循迹行驶

## 🛠️ 硬件清单
- 主控：STM32F103C8T6
- 电机驱动TB6612
- 传感器：超声波模块、红外循迹模块
- 其他：小车底盘、电池、杜邦线

## 📂 目录结构
- `Core/`：主程序代码
- `Hardware/`：硬件驱动代码
- `User/`：用户逻辑代码

## 🚀 如何编译
1. 使用 Keil MDK5 打开工程文件
2. 编译并烧录至 STM32 单片机
